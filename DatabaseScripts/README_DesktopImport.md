# 📥 راهنمای سریع: Import Excel از Desktop

## 🚀 استفاده از اسکریپت `ImportFromDesktop_Simple.sql`

### مرحله 1: آماده‌سازی

1. فایل Excel را در **Desktop** قرار دهید
2. مطمئن شوید فایل Excel **بسته** است
3. ساختار فایل Excel باید این باشد:
   - **ستون A**: کد ملی
   - **ستون B**: تلفن همراه  
   - **ستون C**: نام و نام خانوادگی
   - **ستون D**: کد پرسنلی (اختیاری)

### مرحله 2: تغییر نام فایل در اسکریپت

1. فایل `ImportFromDesktop_Simple.sql` را باز کنید
2. در **خط 14**، نام فایل Excel خود را وارد کنید:

```sql
DECLARE @FileName NVARCHAR(255) = N'YourFile.xlsx'  -- ⚠️ اینجا نام فایل را تغییر دهید
```

مثال:
```sql
DECLARE @FileName NVARCHAR(255) = N'لیست_کاربران.xlsx'
```

3. اگر نام Sheet شما متفاوت است، در **خط 15** تغییر دهید:

```sql
DECLARE @SheetName NVARCHAR(100) = N'Sheet1$'  -- اگر Sheet شما Sheet2 است، اینجا تغییر دهید
```

### مرحله 3: اجرای اسکریپت

1. SQL Server Management Studio را باز کنید
2. به دیتابیس **KhanoumiCore** متصل شوید
3. فایل `ImportFromDesktop_Simple.sql` را باز کنید
4. **F5** را بزنید یا روی **Execute** کلیک کنید

### مرحله 4: بررسی نتایج

بعد از اجرا، نتایج را بررسی کنید:
- تعداد رکوردهای Import شده
- نمونه رکوردها
- خطاها (در صورت وجود)

---

## ⚠️ مشکلات رایج

### خطا: "Cannot open file"
**راه‌حل:**
1. مطمئن شوید فایل Excel **بسته** است
2. مسیر Desktop را بررسی کنید
3. اگر مسیر درست نیست، خط 18 را تغییر دهید:

```sql
SET @ExcelFilePath = N'C:\Users\YourUsername\Desktop\' + @FileName
```

### خطا: "provider is not registered"
**راه‌حل:**
Microsoft Access Database Engine را نصب کنید:
- دانلود: https://www.microsoft.com/en-us/download/details.aspx?id=54920
- نسخه 64-bit یا 32-bit را بسته به SQL Server خود نصب کنید

### خطا: "Ad Hoc Distributed Queries is not enabled"
**راه‌حل:**
اسکریپت به صورت خودکار این را فعال می‌کند. اگر خطا داد، دستی اجرا کنید:

```sql
EXEC sp_configure 'Ad Hoc Distributed Queries', 1;
RECONFIGURE;
```

### خطا: "Invalid column name 'کد ملی'"
**راه‌حل:**
نام ستون‌های Excel را بررسی کنید. باید دقیقاً این نام‌ها باشند:
- `کد ملی`
- `تلفن همراه`
- `نام و نام خانوادگی`
- `کد پرسنلی`

## 📋 ساختار فایل Excel

| ستون | نام فارسی | الزامی | فرمت |
|------|-----------|--------|------|
| A | کد ملی | ✅ | 10 رقم |
| B | تلفن همراه | ✅ | 11 رقم (09...) |
| C | نام و نام خانوادگی | ❌ | متن |
| D | کد پرسنلی | ❌ | متن |

---

## ✅ Validation خودکار

اسکریپت به صورت خودکار:
- ✅ کد ملی را بررسی می‌کند (باید 10 رقم باشد)
- ✅ شماره موبایل را بررسی می‌کند (باید 11 رقم و با 09 شروع شود)
- ✅ تکراری بودن کد ملی را چک می‌کند
- ✅ رکوردهای نامعتبر را رد می‌کند
