# 📥 راهنمای استفاده از اسکریپت Import ساده

## 🚀 استفاده سریع

### مرحله 1: آماده‌سازی

1. فایل Excel را در **Desktop** قرار دهید
2. مطمئن شوید ساختار فایل Excel این است:
   - **ستون A**: کد ملی (10 رقم)
   - **ستون B**: تلفن همراه (11 رقم، شروع با 09)
   - **ستون C**: نام و نام خانوادگی (اختیاری)
   - **ستون D**: کد پرسنلی (اختیاری)

### مرحله 2: تنظیمات (اختیاری)

فایل `ImportExcel_Simple.ps1` را باز کنید و در صورت نیاز این خطوط را تغییر دهید:

```powershell
$ExcelFile = "$env:USERPROFILE\Desktop\یلدا.xlsx"  # مسیر فایل Excel
$SheetName = "Sheet1"                               # نام Sheet
$ServerName = "192.168.87.11"                       # نام سرور SQL
$DatabaseName = "KhanoumiCore"                      # نام دیتابیس
$UserName = "trans"                                  # نام کاربری
$Password = "t@Rrn!r46T5"                           # رمز عبور
```

### مرحله 3: اجرا

1. **PowerShell** را باز کنید (می‌تواند به صورت عادی باشد، نیازی به Administrator نیست)
2. به پوشه اسکریپت بروید:
   ```powershell
   cd D:\ProjectBank\DatabaseScripts
   ```
3. اسکریپت را اجرا کنید:
   ```powershell
   .\ImportExcel_Simple.ps1
   ```

## ⚠️ مشکلات رایج

### خطا: "فایل Excel یافت نشد"
**راه‌حل:**
- مطمئن شوید فایل Excel در Desktop است
- یا مسیر فایل را در خط 8 تغییر دهید

### خطا: "ماژول ImportExcel نصب نیست"
**راه‌حل:**
اسکریپت به صورت خودکار نصب می‌کند. اگر خطا داد:
```powershell
Install-Module -Name ImportExcel -Force -Scope CurrentUser
```

### خطا: "ستون‌های مورد نیاز یافت نشد"
**راه‌حل:**
- مطمئن شوید نام ستون‌ها دقیقاً این است: `کد ملی`, `تلفن همراه`
- نام ستون‌ها باید در ردیف اول باشد

### خطا: "اتصال به SQL Server"
**راه‌حل:**
- نام سرور، دیتابیس، کاربری و رمز عبور را در خطوط 10-13 بررسی کنید
- مطمئن شوید SQL Server در دسترس است
